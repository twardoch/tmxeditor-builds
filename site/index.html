Build a new release

New upstream releases are checked daily. To start a build yourself, open Build distributables and choose Run workflow. Leave the tag empty for the latest stable release, or enter an upstream tag. Increase the build revision to rebuild an existing version.

All three packages must pass their checks before publication. This website then updates automatically. See the README for CLI commands and local builds.
